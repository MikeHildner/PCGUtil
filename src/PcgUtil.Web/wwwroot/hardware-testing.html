Test PCG Util with your workstation

PCG Util edits copies of your .PCG backups — the file you upload is never modified, and every edit downloads as a new file. These checks confirm that your instrument accepts an edited file and recalls the same sounds afterward. Work through them with your own gear and your own file; tick items as you go — progress is saved in this browser, so there's no need to do it in one sitting.

18. Songs needs the .SNG saved beside your backup

Your songs aren't in the .PCG at all — they're in the .SNG that Save All writes next to it. Open both in PCGUtil, and load both back onto your instrument afterwards; loading only one is the usual reason this looks broken when it isn't.

19. Program effects into a combi the offline Copy From Program

When you point a combi layer at a program, the program's insert effects can come along — packed into the combi's free effect slots, so everything already there stays untouched. The FX button beside the layer's program picker shows the plan before anything happens.

20. Re-point references bulk retarget by rule

Programs tab → Edit → Re-point references…: everything that plays the left side plays the right side instead — combi layers, set-list slots, and song tracks. The programs themselves don't move, and the preview shows exactly what a rule touches before you apply.

21. Effect settings read-only — compare, don't change

Every effect chip is clickable now: it opens that effect's actual settings — wet/dry, EQ gains, delay times — straight from your file. Nothing is written here; these checks compare the readout against your instrument's own effect editor pages.

Tone adjust. A combi can tweak each layer's program without editing the program — brightness, envelopes, an organ's drawbars. Where a timbre does, its row shows a ✎ count; click it to see what, by name.

22. Program settings read-only — compare, don't change

Every program now opens to its whole interior: oscillators, filters, envelopes, LFOs — and for an EXi program, whichever engine it runs, in that engine's own words. Click ⚙ Settings on a program row, or the ⚙ beside a combi layer to read the program that layer plays. Sections start closed; the Find box is the fast way to one setting. Nothing is written here.

Known limitation. If you overwrite a program a song track uses (paste or clear, rather than move it), the track keeps its slot and will play whatever now lives there — the sound it used is gone from the file. The Songs tab tells you when this happens.
Pass criteria. The edited .PCG loads cleanly, and every patch and reference recalls the same sound as before — only the positions you intentionally changed should differ.
